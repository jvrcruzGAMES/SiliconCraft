# N language standards

Both N standards compile to SiliconCraft Assembly and `.o` bytecode. The installed SoC must support the instructions generated by the compiler.

| Standard | Status | Files | Start here |
|---|---|---|---|
| N1 (N standard 1) | Deprecated; retained for existing programs | `.n`, project entrypoint `main.n` | [N1 chapter](n1/README.md) |
| N2 (N standard 2) | Default standard for new programs | `.n2`, project entrypoint `main.n2` | [N2 chapter](n2/README.md) |

## Compile and install

Use the **Code Compiler** for a single source file and the **Project Compiler** for a folder or ZIP project. Both provide an N1/N2 standard selector; opening `.n` or `.n2` selects the matching standard. Use the **Assembly Writer** for standalone Assembly files. Programs are compiled into bytecode before being written to ROM or storage with the Programmer.

N2 provides classes, lists, maps, and bundled libraries such as `<std>`, `<Glass>`, `<AudioKit>`, `<DeviceKit>`, and `<Network>`. N1 has its own syntax and hardware builtins; do not copy N2 library imports into an N1 program.
