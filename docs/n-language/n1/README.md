# Chapter 3: N1 — deprecated

N1 (N standard 1) is deprecated. This chapter preserves the reference and examples needed to maintain existing `.n` programs. Use [N2](../n2/README.md) for new high-level software.

1. [Language and hardware reference](reference.md): variables, operators, pointers, tables, storage, graphics, audio, functions, imports, interrupts, and inline Assembly.
2. [Peripherals and networking through inline Assembly](peripherals-network.md): access the CPU mailbox instructions from legacy programs.
3. [Examples](examples/README.md): standalone programs and a modular project.

Compile `.n` files in N1 mode using the Code Compiler. For projects, choose `main.n` as the entrypoint in the Project Compiler. Burn the resulting program with the Programmer; see [Getting Started](../../getting-started/README.md).
